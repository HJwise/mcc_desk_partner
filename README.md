# mcc_desk_partner

> **mcc_desk 솔루션 파트너 채널** — FA·장비공급 업체를 위한 제품·서비스 안내

산업용 데스크톱 모션 플랫폼 **mcc_desk**의 솔루션 파트너 채널 공개 홍보 사이트입니다.

> 본 사이트의 콘텐츠는 데모 단계의 **가상 홍보 자료**입니다. 서비스·상품은 준비 중이며, 오픈 시 스펙 및 서비스 내용은 변경될 수 있습니다.

## 사이트

- 발행 URL: https://hjwise.github.io/mcc_desk_partner/
- 발행 방식: **GitHub Pages** (Source: `main` 브랜치 / `/docs` 폴더, 정적 HTML)
- 통합 허브: https://hjwise.github.io/mcc_desk_solution/
